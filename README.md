# BankSystem

Hybrid Queue Management System prototype built as a standalone .NET Windows Forms application.

The system lets bank customers join a queue, receive a ticket, check their queue position, view estimated waiting time, and receive notifications when their turn is approaching. Bank staff can manage service queues through an admin panel by calling, skipping, and completing tickets while viewing basic analytics.

## Features

- Customer queue registration
- Service categories for cash, account, and loan services
- Automatic counter routing
- Generated HTML tickets with QR code
- Queue position and estimated wait tracking
- Admin panel for calling, skipping, and completing tickets
- Basic queue analytics
- Local JSON data storage

## Technology

- C#
- .NET Windows Forms
- JSON file persistence
